# Tutorials

Hands-on walkthroughs for Aspected Studio. Early tutorials stay short: which
control to use and what you should see. Tutorials 4 and 5 go deep on
**metrics**: what each number means, when it matters, and how to use it while
tuning weights.

Do these in order the first time. Later, jump to the one you need.

| # | Tutorial                                               | You will                                                                |
| - | ------------------------------------------------------ | ----------------------------------------------------------------------- |
| 1 | [Connect and seed the catalog](01-connect-and-seed.md) | Run Aspected, open Studio, connect, build the demo index                |
| 2 | [Indexes and documents](02-indexes-and-documents.md)   | Browse schema, upload and delete a document, read the Request Inspector |
| 3 | [Search](03-search.md)                                 | Run a sparse search on the API-shaped Search page                       |
| 4 | [Playground](04-playground.md)                         | Tune weights, pin Compare A/B, interpret Overlap, RBO, and movement     |
| 5 | [Catalog scorecard](05-catalog-scorecard-demo.md) | Import a golden set, grade quality, read nDCG and friends, fix weights |
